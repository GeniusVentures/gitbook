# Public Roadmap

## Current release status — October 2026

**SuperGenius mainnet implementation is complete; public mainnet has not launched.** GNUS.ai is deliberately coordinating public activation with Genius Cognitive System (GCS), Genius AI Boss, and other initial applications. The original Q2 2026 public-launch target passed; it is **not** evidence that core mainnet implementation is unfinished. No replacement public-launch date has been announced.

See [Platform Status](release-status.md) for the distinction between implementation, public activation, and separate EVM token contracts.

## Upcoming public-launch gates

These are readiness areas, **not completed milestones or dated commitments**:

- [ ] Complete and validate launch-critical GCS integration and workflows.
- [ ] Prepare Genius AI Boss and the initial application set for deployment.
- [ ] Complete the required end-to-end checks for application, network, verification, and settlement paths.
- [ ] Confirm onboarding, operations, documentation, and support readiness.
- [ ] Announce and execute public mainnet activation.
